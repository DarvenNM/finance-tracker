💰 Personal Finance Tracker

A web-based **Personal Finance Tracker** built with Python and Streamlit to help users manage income, expenses, budgets, and financial reports in one place.

🚀 Features

* 🔐 User registration and login
* 💰 Income and expense tracking
* 🏷️ Expense categorization
* 📊 Dashboard with financial insights
* 📈 Expense visualization
* 💵 Budget tracking
* 📄 Downloadable PDF financial reports
* 📧 Email-based financial summaries
* 🤖 Personalized financial recommendations
* 🗑️ Transaction management

🛠️ Technologies Used

* Python
* Streamlit – Web application framework
* SQLite – Database management
* Pandas – Data processing
* Matplotlib – Data visualization
* ReportLab – PDF report generation
* SMTP / smtplib – Email functionality

⚙️ How to Run

1. Clone the repository

```bash
git clone https://github.com/DarvenNM/finance-tracker.git
```

2. Open the project folder

```bash
cd finance-tracker
```

3. Install the required packages

```bash
pip install streamlit pandas matplotlib reportlab
```

4. Run the application

```bash
streamlit run app.py
```

The application will open in your browser.
